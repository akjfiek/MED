# Released MED Modules

- `MambaVision.py` contains the Mamba mixer, attention blocks, and C3k/C3k2 backbone wrappers.
- `SAQE.py` contains the localization-quality estimator and detection-head classes.

These files require their documented dependencies and Ultralytics model-parser integration. They are selected source components rather than a complete MED detector. See the [repository README](../README.md) for dependencies, integration notes, and release scope.
